# 全战三国 Mod 固定排序

将官方启动器的 55 个 mod 恢复为指定截图中的顺序，保留每项开关状态。

## 使用

Windows，需要 Python 3.8 或更高版本，使用标准库，无需第三方模块。

1. 下载 ZIP 并完整解压。
2. 正常关闭游戏和全战官方启动器。
3. 双击 `02-一键排序.cmd`，完成后重新打开启动器。

`01-预览排序.cmd` 仅检查和显示顺序。`03-恢复备份.cmd` 恢复最近一次操作前的完整启动器配置。

## 固定清单

- 严格保留截图中的 1–55 顺序。
- 第 17、18、19、27 项关闭，其余开启；第 55 项以第二张截图为准，开启。
- `顺序清单.txt` 提供可读清单，`order.json` 保存实际 mod 文件标识和本机路径。
- 这是个人固定清单，迁移游戏安装位置后需要检查路径。

## 备份与校验

修改前自动备份完整配置；写入后逐字节校验。启动器或游戏运行时拒绝写入。固定 mod 文件缺失、出现重复标识或配置中存在清单外的已安装 mod 时停止。

目标配置：`%APPDATA%\The Creative Assembly\Launcher\20190104-moddata.dat`

备份位置：目标配置同目录的 `three-kingdoms-order-backups` 文件夹。

完整备份也包含其他全战游戏当时的启动器设置，恢复会一起还原。恢复前会再备份当前配置。

验证记录见 `验证结果.txt`：已验证副本排序、状态保留、备份恢复及真实进程写入拦截；未启动游戏验证兼容性。

本仓库仅包含脚本和排序清单，不包含 mod 本体或游戏文件。
